# AI 이미지·영상 — Codex 먼저 · 유료 1건 · 영상화 직전 점검 (세로)

> 원본: 영상제작 `길라잡이/AI영상-주의사항.md`(10-01 «반실사» 실패에서 만든 문서 — 사장님 «이 실패한 기록들 … 길라잡이에 영상만들때 주의사항 … 꼭 참고해야하는 방향으로 경로잡고 정리해») → 쇼츠광고·롱폼 `ai-video.md`.

## 0. 가장 중요한 한 줄

**시작·끝(참고) 이미지의 질감이 영상에 그대로 옮겨 간다.** 이미지가 CG면 영상도 CG(반실사), 사진이면 실사. 모델 탓이 아니다 — 프롬프트는 그대로 두고 시작 이미지만 사진풍으로 바꾼 시험(9크레딧)으로 확정했다(분양4 05, 10-01). **원인을 모르면 바꾸는 것을 하나만 두고 시험한다**(«제미나이가 문제인지도 확실하지않잖아»).

## 1. 돈 순서

- **이미지는 전부 Codex 로 먼저**(마스터피스·시작프레임·레퍼런스·시안 — 추가 과금 없음). 유료는 Codex 로 못 하는 영상화·업스케일에만.
- **유료 생성은 장면당 한 건** — 후보 비교는 Codex 시작프레임 단계에서. `count` 2 이상·같은 프롬프트 변형 금지. 발주 전 `get_cost`, 발주 뒤 실제 차감 대조, 크레딧 누계를 기록에.
- 분양4 하루 207크레딧 중 87 이상이 반려·재작업으로 버려졌다(05 v1·v3, 06 v1·v2) → 모드 B(밤)에서는 유료 영상화를 하지 않는다.

## 2. Codex 이미지 프롬프트에 꼭 넣는 것

```
Photographic style (real camera photo, full-frame 24–35mm, eye level 1.6 m or DJI drone, natural light, low saturation,
real material texture, slight haze) — NOT 3D render, NOT illustration, NOT ad perspective drawing.
Real Korean people at mid distance, large (1/4–1/3 of frame height), natural poses, some slight motion blur.
No text, signs, logos, numbers.
```
- 영어 자기완결형 · 복사 대상 경로(이 저장소 안) 지정 · «후처리 명령 실행 금지, 생성 결과를 복사만» · 한 세션에 몰아서 · 같은 인물은 앞 그림을 `view_image` 로 물림 · 스타일은 세션 안에서 하나(실사 사진 / 3D 장난감 / 2D 플랫).
- 참고 자료가 CG(투시도·조감도)면 «구조만 같게, 질감은 따라 하지 말 것». 실제 입주 아파트 사진으로 물리면 AI 티가 빠진다(모델하우스 전시품 사진은 빼라).
- 사람은 **성인만** 넣으면 Gemini 를 쓸 수 있다(미성년 거절 → Seedance, 비싸다).
- **세로 비율**: portrait 1024×1536 은 2:3 이다. **Kling 출력은 `aspect_ratio` 보다 시작프레임 비율을 따른다** — 2:3 시작프레임이면 결과가 2:3 이라 9:16 으로 잘라야 했다(작업기록-0923). 시작프레임을 9:16 으로 맞춰 올린다(☐ Codex 가 9:16 을 직접 주는지, 크롭·아웃페인트로 맞출지 첫 건에서 확인).

## 4. 길이 · 원테이크 · 이어 붙이기

- **구간별 배속 변경 금지** — 2배속↔0.8배속은 «중간중간 멈춤»으로 보인다(10-01). 생성 길이 = 대사 구간 길이(3·4·5초), 1배속(±5%). 배속은 사장님이 거신다(«배속은내가걸게»).
- **원테이크**(«뚝뚝 끊기잖아, 원테이크로»): 시작·끝 이미지를 둘 다 넣으면 컷이 생긴다 → 끝 이미지 빼고 시작 1장 + 프리비즈 + «single continuous take, no cuts». 받은 뒤 0.33초 간격 프레임으로 컷 바뀜 확인.
- 앞 컷 끝 프레임에서 이어야 하면: 타임라인에서 **마지막으로 보이는 프레임**(사장님 확대값까지 반영해 잘라냄)을 시작 이미지로.
- 유료를 아끼는 길: 끝 프레임 정지 + 애펙 확대 전진(100→122%, 3초) · Codex 사진 + 느린 밀기 · 정지 + 켄번스 + 음성으로 애니매틱.
- AI 영상에 글자를 넣지 않는다 — 글자는 위에 렌더러로.

## 5. 영상화 직전 점검 — 한 줄씩

```
[ ] 시작(·끝) 이미지를 직접 열어 봤다 — CG 냄새(쨍한 채도·장난감 같은 꽃·작게 박힌 사람) 없음
[ ] 시작프레임이 9:16 (2:3 이면 결과도 2:3)
[ ] 사람은 화면 높이 1/4~1/3, 실제 한국인, 자연스러운 옷 · 미성년이면 Seedance
[ ] 이미지에 글자·간판·로고·숫자 없음
[ ] 프리비즈가 필요하면 Kling 아님 · 이어지는 편과 같은 모델
[ ] 한 컷 장면이면 끝 이미지 뺐다 · 생성 길이 ≈ 대사 구간(배속 바꾸기 없음)
[ ] 확인②에서 사장님이 고른 시작프레임 · 이 장면 유료 1건만 · get_cost · 크레딧 누계 기록
```
