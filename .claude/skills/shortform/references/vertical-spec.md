# 세로 규격 — 확정값 · 재서 채울 칸 · 가로에서 옮길 때 바꿀 점 (기준값은 이 문서 한 곳)

규칙: **세로 수치를 지어내지 않는다.** 첫 작업 때 사장님 세로 편집(`.prproj` 자동저장본 사본)·정지 화면·레퍼런스에서 재서 «☐» 칸을 채우고, 채운 날·잰 곳을 적는다. 다른 문서는 숫자를 다시 적지 않고 «→ vertical-spec.md N장»으로 가리킨다.

- 분양 시장 상위 5편(메타 광고 라이브러리, 전부 360×640): M01 62.8초·M06 49.0·M07 50.9·M10 31.8·M16 34.6초 — 영상제작 `레퍼런스/시장조사-5편-전사.md`. 유니트 실사 원테이크 위 한 줄 자막 + 스티커(M07·M10·M16) / CG + 고속 그래픽(M06, 0.8초당 자막 1블록) / 모형 비행 + 카라오케 자막(M01).
- 엔트리 릴(1080×1920 60fps, 15초): 컷 9·평균 1.67초·컷-박 맞춤 62% — 쇼츠광고 `study/entry-reel-opus.md`.
- 레퍼런스6(42.1초, 송도 자료 몽타주): 컷 평균 1.6초·분당 36컷, 긴 홀드 2.5~6.0 / 기본 1.0~1.5 / 연타 0.43~0.53초 — 쇼츠광고 `editing-premiere.md` 5-3.
- 타이포 레퍼런스 10편은 **전부 가로**다(세로로 옮길 때 J-7).
- 강의형 1인 토크 쇼츠 30편(10-13, 360×640, 5채널 × 6편): 3단 틀 — 위 고정 제목 2줄(0~약 20%) / 사람 가슴 위(머리 윗끝 약 14~25%) / 자막 한 줄 약 65~77%, 5~17자, 1~2초마다 교체 / 아래 로고·빈 띠. 전환 하드컷 30/30, 리듬은 원테이크 크롭 줌(지식인사이드 30초에 약 9회). 사람 전체 덮기는 구체물·고유명사를 말할 때 2~4초(쩐문가 6/6), 덮어도 띠·자막 유지.
