# 납품 전 점검표 — 한 줄씩 확인하고 결과를 보고에 적는다 (숏폼)

사장님 09-28 «규칙 누락 현상 심함» — 알고도 빠뜨리지 않는 게 핵심이다. **사장님께 보여 드리기 직전**에 해당 표를 한 줄씩 본다. 새 피드백 → **규칙 한 줄(SKILL 4장) + 점검표 한 줄(여기)** + 기계로 볼 수 있으면 점검기.
어느 표: 모든 편 = **S표**(구조·사실) + **V표**(연출) + **D표**(소리) + **F표**(납품) / AI 컷이 있으면 + **E표**.

## 점검기 (☐ 이식 대기)

**S6 은 `tools/s6_check.py`(항목표는 파일 머리말·`s6-longform-shorts.md` 3장)가 점검기다 — ERROR 0 이어야 납품.** 아래는 다른 유형용 원본 도구(쇼츠광고·롱폼 저장소에만 있음, 이 저장소에 이식 안 함 — 그 유형을 맡게 되면 옮긴다): 쇼츠광고 `rule_check.py`(`check_plan` 화면 목록: 소스 중복·모형·까만 화면·자료 2초·전환 연속·자막 원문 / `check_sfx` 5-2·5-2b·5-3 / `check_tone`) · `html_motion` 렌더 전 점검(겹침 ERROR·인지 텀·3색 WARN) · `sfx_audit.py` · 롱폼 `glyph_check.py`. 새 렌더 도구를 만들면 반드시 끼운다(ERROR 면 멈춤, `--무시` 로 넘기면 위반 목록을 보고에).
