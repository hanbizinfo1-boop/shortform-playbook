# 상황 강령 — 숏폼 한 편 안에서 «지금 무슨 일이 일어나는가»별 원칙 (학습 전 뼈대)

> 원형: 롱폼 `situation-playbook.md`(PB-01~18, 사장님 10-08 «자료설명할때, 자료를 띄우며 연출할때, 브랜드를 표현할때, 사람이나와서 말을할때 등등 여러가지 행동에 따른 그리고 상황에따른 강령과 템플릿 설계도 굉장히중요할거같아», 10-12 확정). 숏폼은 30~60초 안에 훅·근거·반론·CTA 가 다 들어가므로 상황을 **광고 문장의 역할** 기준으로 다시 나눴다.
> 고르는 순서: **줄마다 상황(SP)을 붙인다 → 그 강령을 편다 → 강령이 허락한 서랍·템플릿 안에서만 고른다 → 느낌(TN)이 비중을 조절한다.** 느낌은 강령의 «하지 마라»를 풀지 못한다.
> 근거 표시: 사장님 말씀(날짜) > 통과 장면 > 학습분(레퍼런스·일반론).

## 0. 모든 상황 공통

1. **주인공은 하나** — 한 순간 화면의 주인공(사람·자료·글자·캐릭터·브랜드) 하나, 나머지는 물러선다.
2. **말이 시계다** — 모든 움직임은 그 말의 단어 시각(±2프레임, 분양 09-29 «각 단어 시작에 이미지 들어오는 정합성 2~3번 체크»). 말 없는 편(S5)만 BGM 박.
3. **앞뒤 맥락 먼저**(10-07) — 앞에서 보여 준 것을 이어받는다.
4. **그림은 진짜 이미지, 도형 흉내 금지 · 화면 글은 개념어**(말 복사·«» 대사·옆에 문장 다시 띄우기 금지).
5. **인지할 텀 0.6초**, 한 문장 새 요소 2~3개, 빈 구간을 메우려 끼워 넣지 않는다.
6. **같은 연출 연달아 금지**, 비교 판 연달아 금지, 통과 틀 복붙 금지.
7. **자막·고정 띠·사람 자리는 비운다**(겹침 없음 — `vertical-spec.md` 2장 칸이 정해지면 점검기 금지 구역으로).
8. **효과음은 그래픽에 붙고 뜻에 맞는다**.

## 0-1. 갈래 용어 사전 (사장님 말 → 통과한 것)

반려 1위가 «사장님 말과 갈래가 어긋남»이었다(롱폼 bisa-learning). 같은 말을 들으면 이걸로 푼다.

| 사장님 말 | 통과한 것 | 아닌 것 |
|---|---|---|
| «의인화» | 글자가 적힌 팔다리 달린 인형 캐릭터가 행동하는 역동적 모션그래픽(빡이사 11 2판, 외부 «쌉 고수 같다») | 실사 직원 사진 |
| «실제 세팅 페이지에서 설정하는 느낌» | 실화면 칸을 확대해 값을 직접 타자(08 2판, 외부 «상상도 못한 방법인데 쥐깁니다») | 휴대폰 비교 판 |
| «핸드폰으로 보는 화면» | 광고를 **보는 사람** 시점일 때만 | 설정 이야기 |

| «노트에 글씨 쓰면서 적는 느낌» | 손글씨 + 형광펜 게이지(펜 그림 없음) | 카드·썸네일 |
| «모션그래픽처럼 화려하게, 자료가 날아다니며» | 어두운 무대에 **실제 자료** 카드가 깊이에서 날아듦 | 아이콘 카드 |
| «상황 재현» | 실화면 위에 그 상황 UI 재현(업체 ○○) | 카드뉴스(«카드뉴스 말고 시각적으로 재현») |

| «찍 긋는 연출» | 끝이 가늘어지는 붓 획 + 앞머리 빛(3안 J-9) | 직사각 줄 |
| «깨지면서 전환» / «화면 전체적으로 깨졌으면» | 화면 전체 유리 금 → 36조각 흩어짐(3안 8판) | 글자만 갈라짐 |
| «빨려 들어가면서 전환» | 0.37초 두 바퀴 반 가속 회전 + 속도선, 다음 장면은 반대로 풀림 | 느린 줌 |
| «고급지게 / 저렴하지 않게» | 매거진·3D·실재 질감(나무·종이) 바탕 + 물리 동작 전환, 바탕 시안 2~3개 먼저 | 단색·기본 도형·기본 전환 |

## 2. 상황별 강령

### SP-01 훅
- **하라**: 첫 프레임이 소리 없이 읽히게(큰 글자·결과 장면). 첫 5초 안에 후킹 요소 3개. 오프닝은 영상(바닥은 실제 영상, 이미지는 그 위에 얹는다 — 09-27).
- **하지 마라**: 이미지로 시작 · 긴 로고 인트로 · 레퍼런스 첫 대사 복사.
- **3안 학습**: 첫 후킹이 «멋이 안 산다»의 원인 = 글자 작음 · 연한 바탕에 검정 · 무게감 없음(10-13) → 시안 3개(큰 입체 블록 / 어두운 시네마틱 / 두꺼운 3D 블록 글꼴).
- **소리**: 시작 무음 0.3~0.5초 → 첫 프레임 쿵(인기 9편 실측) 또는 라이저가 후킹 끝까지(분양과오2 RISER 3.34~6.54).

### SP-03 근거·숫자
- **하라**: 숫자는 카운터(자리마다 세로로 굴러 큰 자리부터 멈춤, 고정 폭) + 단위 작게 고정. 말에 나온 숫자만, 근거 표 «일치»만. 공고 문구는 실제 견본 위 형광펜(대표 설명형 설계).
- **하지 마라**: 시청자에게 계산 시키기 · 차이가 작은 값을 막대로(2.3% 차이 막대는 비율을 속인다 — 분양 진행기록) · 더미 숫자 막대 · 근거 없는 꼬리말.
- **소리**: 숫자 = «세는» 굴림 소리 한 파일(낱개 틱을 큐로 넣으면 반복 규칙에 걸린다).
- 강조 숫자는 박힌 뒤 1초 이상 머문다(10-13 «체류시간 0.5초 정도만 더길게»).

### SP-05 손실·공감
- **하라**: 아픈 데를 짧게, 장면은 그 상황을 겪는 사람(Codex 사진·2D). 펀치인 한 번.
- **하지 마라**: 조급함 조장 · 남의 얼굴 실사(동의 없음) · 반실사 질감.

### SP-06 비교

- **하지 마라**: 비교 연출 연달아(직전 3컷에 비교가 있으면 다른 강령으로) · 아직 말 안 한 쪽을 미리 보이기.

### SP-08 회사·전 과정 / SP-10 혜택 나열
- **하라**: 여러 항목 = **정렬된 목록을 처음부터 두고 지금 항목에 노란 형광펜**(3안 «차라리 글자가 처음에 정렬되게 배치되고 해당하는 거 나올때 노란색으로 표시»). 넘어가는 느낌은 배경(그 항목의 실제 견본)이 낸다. 혜택은 물건에 담는다(나무 토막이 박히고 글자가 새겨짐, 핵심어 진한 파랑). 한 글자씩 보일 땐 글자마다 물건 하나(«전부가능» 토막 4개).
- **하지 마라**: 카드마다 이름 하나씩 띄우기(반 박 카드는 글이 안 읽혔다) · 아이콘 카드 나열 · 체크리스트 카드·제비뽑기(10-12 «너무 저렴해»에서 버림) · 빵빠레(빛줄기·고리·색종이).

### SP-09 사례·이야기
- **하라**: 같은 인물 2D 상황극(같은 캐릭터 여러 동작) 또는 Codex 실사 사진. 실사 영상이 꼭 필요하면 유료 1건.
- **하지 마라**: 실제 고객 얼굴·상호 · 사례 고지 없이 단정.

### SP-12 CTA
- **하라**: «더 알아보기» 버튼이 아래 화면 밖에서 끌려 올라와 멈춤(감속, 튕김 없음) → 탭(3안 6판). 버튼 문구는 랜딩 첫 화면에 맞춤. 끝 버튼 하나. 대상 호명 바로 뒤.
- **하지 마라**: 중간·끝 버튼 중복 · 가짜 «LIVE 시청자 수» 같은 속이는 장치 · 짜치는 이모티콘(빨간 화살표).

### SP-13 브랜드·로고
- **하라**: 실제 로고 파일(새로 그리지 않음 — `소재/브랜드/` ☐), 브랜드 색. 로고 엔딩 3종(크림·남색·레이저 S, 쇼츠광고 10-08 완성, 레이저 바탕 회백 #E9EAEC). 로고 효과음은 짧은 소리만(휘익 → 맑은 종 → 반짝 약 1.8초), 그 구간 BGM −8dB.
- **하지 마라**: 로고 AI 재생성 · 화음·패드 같은 «배경음» 로고 소리(«아니 배경음을 넣는게아니라 로고효과음만»).

### SP-14 전환점
- **하라**: 큰 변화 앞 0.3~1초 비움(BGM 내림) → 변화 순간 타격(«비움 + 타격»이 무게를 만든다). 전환은 물리 동작(왼쪽 푸시·반쪽 커튼·토막 뒤집기·글자 속으로·빨려 들어감·화면 깨짐). 같은 전환은 한 편 3번까지.
- **하지 마라**: 크로스 디졸브로 때우기 · 반쪽 커튼 가운데 이음선(10-13) · 흔들기·스트로브.

### SP-15 실사 공간·사람
- **하라**: Codex «사진기로 찍은 사진» 톤 이미지 → 느린 밀기/패럴랙스(유료 0). 유료 영상은 확인② 뒤 1건, 생성 길이 = 대사 구간(1배속). 끝 프레임 정지 + 애펙 확대 전진(100→122%)으로 «조금 더 전진»(분양4 06, 유료 0).
- **하지 마라**: CG 투시도 질감을 참고로 넣기(반실사) · 구간별 배속(멈춤처럼 보임) · 시작·끝 이미지 둘 다 넣어 컷이 생기게.

### SP-16 가려야 할 화면
- 같은 결의 가짜 화면을 다시 그린다(업체 ○○ · 010-0000-0000). 실화면은 주소창·탭·북마크·왼쪽 위 상호를 자른다(10-12 외부 피드백 «왼쪽 상단 … 상호명 모자이크가 안됐고»). 전 구간 자동 모자이크보다 **가릴 구간 목록(시각·위치)부터** 드린다(10-06 «내가 알아서 블러처리할게»).

## 3. 겹칠 때 우선순위

`SP-16(가림) > SP-07(비용 반론) > SP-03(근거 숫자) > SP-06(비교) > SP-08·10(나열) > SP-05 > SP-09 > SP-02 > SP-11`
— 바깥 상황이 화면을, 안쪽 상황이 강조를 정한다. 훅(SP-01)·CTA(SP-12)·로고(SP-13)는 구조(ST)가 자리를 먼저 박는다.

## 4. 아직 비어 있는 것

- ☐ 각 SP 의 템플릿 우선순위(`drawers.md` 서랍이 채워지면 SP 마다 `templates` 목록).
- ☐ 판별 신호의 정확도(첫 대본들로 잰다).
- ☐ 학습분 줄(소리 수치·전환 길이)은 첫 건 검수 뒤 확정.
