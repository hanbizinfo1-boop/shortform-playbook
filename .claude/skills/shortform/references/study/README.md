# 레퍼런스 학습 노트 — 쓰는 법

사장님이 주신 레퍼런스를 «정독»한 노트를 영상마다 한 파일로 둔다. 노트는 **근거(시각·화면·말)** 이고, 작업할 때 펴 보는 «무엇을 참고하나»는 상위 문서(`../drawers.md` · `../structure-playbook.md` · `../situation-playbook.md` · `../vertical-spec.md` · `../sfx.md`)에 모은다. 절차는 `../learning-plan.md` 3장.

`_tmp/` 는 git 에 안 올라간다 — 노트에는 **영상 URL + 시각**을 적어 다른 PC 에서도 다시 만들 수 있게 한다. 이미지 파일은 커밋하지 않는다.

## 노트 틀

```
# <짧은 이름> — <원제목>
- URL · 길이 · 해상도/fps(세로인가) · 올린 곳 · 조회수/게재 일수(반응 근거) · 사장님이 붙인 목적(원문)
- 수치(summary.md): 컷 수·평균 컷 길이 · 자막 블록 수·블록당 글자·노출 시간 · 강한 타격/분 · LUFS · BPM · 맞춤 비율

## 1. 한 줄 요약 — 이 영상에서 가져갈 것
## 2. 구조 — 초 단위 (훅 · 본문 역할별 · CTA) — 대본 전사 포함
| 시각 | 역할(SP) | 말 | 화면(무엇이 보이나) | 화면 글 | 움직임·전환 | 소리 |
## 3. 세로 화면 배치 — 고정 요소(상단 제목·대표번호·혜택 띠) · 자막 자리·크기 · 사람 자리 · 자료 자리 (y 비율로)
## 4. 기법 카드 (기법마다) — 이름 · 무엇 · 왜 먹히나 · 시각(근거) · 우리 도구로 하는 법 · 한비즈 적용 예
## 5. 설계자 관점 변형 — 이 영상이 «하라는 방식» → 우리 파이프라인에서는 이렇게(왜)
## 6. 우리 규칙과 부딪히는 것 (SKILL 4장 · checklist) — 그대로 쓰면 반려될 것
## 7. 못 본 것 · 불확실 (소리는 귀로 못 들음 등)
```
