# 자막 — 원문 · 위치 · 스타일 · 싱크 (숏폼)

## 1. 글

- **자막 글 = 사장님 타임라인·대본 원문**(whisper 받아쓰기 금지 — 09-28 «20분컷인데 20분 꽉이라고 한 이유가 뭐야»). 받아쓰기는 시각만.
- **중복 자막 금지** — 위에 같은 말을 크게 또 띄우지 않는다(«중복자막은 왜 넣는거야»). 그 자리엔 영상이나 실자료.
- 자막은 한 줄이 기본(분양). 줄바꿈은 의존명사(분들·것·수·때…) 앞에서 끊지 않게 벌점(«계셨던 / 분들» → «계셨던 분들 / 30초만 집중해봐», 분양 진행기록).
- **긴 자막 나누는 자리 = 어색함 점수가 가장 낮은 띄어쓰기**(10-14 «그런데 인스턴트 / 양식 같은경우에는 이아니라 그런데 인스턴트 양식 / 같은 경우에는 이렇게 잘라야지»): 조사·어미(은·는·을·를·에서·고·면·요…)·쉼표 뒤는 자연스럽고 «같은·같이» 앞도 자연스럽다. **명사+명사(인스턴트 / 양식) · 꾸미는 말+받는 말(넘어갈 / 수, 잘 되는 / 광고) · 의존명사 앞(밀어주는 / 것을) · «의» 뒤(여러분들의 / 눈에)**는 금지. «광고»처럼 «고»로 끝나는 명사는 어미로 보지 않는다. 구현 `tools/s6_render.py` `break_cost`, 점검 `s6_check` D3.
- 글자 강조를 과하게 하지 않는다 — 글자 대신 그림·모션(09-28 클라이언트 «글자가 너무 많이 강조됨»).
- 강조어는 흰색으로 시작해 **말하는 순간(그림과 묶인 말은 그림이 들어오는 순간) 색이 바뀐다** — 단, 사장님이 지정한 줄만(09-29 «커뮤니티시설 설명할때만 색깔 변경하게해주고 나머지는 원래대로»).

## 2. 스타일 — 확정 1개 + 이력

- **설명형(말 있는 편) = A2 불투명 회색 띠**(10-08 확정) — 값은 `vertical-spec.md` 1장.
- 말 없는 편은 자막 대신 타이포. 콜라주 배경처럼 띠가 필요 없는 자리는 «오려 붙인 글자»(음절마다 색 종이 조각, ±5°, 2프레임 간격 탁탁, 10-12 «띠 없이할수 있을테니까 자막 멋드러지게»).
- 한 편 안에서 스타일을 섞지 않는다.
- 이력(다시 돌지 않게, 쇼츠광고 `editing-premiere.md` 7장): 구워 넣음 → 별도 PNG 트랙 → 띠+외곽선 «띠가 어색하다» → 외곽선만 «비친다»(정체: 첫 프레임 45% 투명 램프) → 알파 MOV+모션 블러 «전부 똑같다» → 4종 → 레퍼런스8 방식 «효과 빼고 내가 설정하게» → 정지 PNG «구워져서 테두리를 못 고친다» → SRT. 공존한 세 스타일: A 불투명 띠 / B 띠 없음+검정 외곽선 9px / C 얇은 외곽선 1~5px+옅은 그림자(×0.35).
- **구운 자막은 프리미어에서 테두리를 못 고친다** → 사장님이 직접 만지실 수 있게 SRT 를 같이 낸다.
- 불투명도는 첫 프레임부터 절반 이상(투명하게 시작하면 «배경이 비친다»).

## 3. 위치

- **S6(채널 강의 쇼츠) 확정: 자막 중심 y 1440** — `vertical-spec.md` 1장(10-13). 그 밖의 유형은 ☐(`vertical-spec.md` 2장) — 참고: «너무 하단» 반려 → 분양 y 1150(≈0.60H), 광고주 «가운데·조금 크게» → y 960.
- 자막과 판(자료)이 겹치면 판을 피해 가장 가까운 빈 줄로.
- 레퍼1(세로 광고): 가운데(가슴 높이)에 1~2어절 단어 자막, 상단 고정 제목 2줄은 따로.

## 4. 등장·싱크

- 기본: 팝 130→100%(0.216초), 핵심 줄 1→120→100%(사장님 분양과오2 실측).
- 대안: 레퍼런스8(페이드 + 0.94→1.0 3~4프레임, 머무는 동안 1.0→1.02) / 레퍼런스6(좌→우 와이프 0.07초).
- **자막은 소리보다 0.05초 먼저** — 강제정렬만으로는 «느리게» 들린다(파열음·숨이 먼저 나옴): 무음이 끝나는 지점(파형 −28dB)으로 당기고 0.05초 더 앞세움(«자막이 음성에 비해 살짝 느린 지점들이» 09-22).
- **자막 시각의 정본 = 대본 글자 강제 정렬의 첫 음절**(`tools/align_chars.py`, wav2vec2 한국어 · 10-14 «자막이랑 목소리 나오는 타이밍 정확도도 너무낮은데»). whisper 단어 시각은 앞 숨을 먹거나 이어 말하는 중간에 찍혀 0.3~0.6초 틀리고, 음량 쉼만으로는 어느 쉼이 자막 경계인지 모른다(10-14 실측: 정렬로 판정하니 원 구운 자막이 맞은 곳이 많았다) → **둘 다 자막 시각에 쓰지 않는다.** 계획 맞춤 `tools/caption_sync.py --fix`(묶인 확대·표시·효과음 키도 같이 이동), 긴 자막 나누는 시각도 정렬. 숫자·영문으로 시작하는 자막은 정렬이 흔들려 옮기지 않고 귀로 확인.
- (옛 규칙, 10-14 폐기) «medium·large-v3 두 모델 평균 근처» — 위 정렬로 대체.
- 음성 배속을 걸면 SRT 시각 ÷ 배속(분양 1.15).
- 대본↔나레이션 무STT 정렬(받아쓰기가 없을 때): 10ms RMS 로 말하는 구간을 찾고 글자 수 비례로 나눈다 — 구절 수와 줄 수를 억지로 1:1 로 맞추면 안 된다(9줄 어긋남 사례).
- 끝나면 **완성본 소리에 자막(.srt) 글자를 강제 정렬**해 대조 — 첫 음절보다 0.15초↑ 늦게 뜨면 ERROR(`s6_check` D2). (분양1 4차는 받아쓰기 대조로 34줄 0.1초 안 — 받아쓰기 대조는 위 이유로 대체)
