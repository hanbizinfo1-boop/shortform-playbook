# S6 롱폼 → 쇼츠 — 한 편 흐름 · 규칙 지도 · 점검기 (한 곳)

한비즈 채널 강의형 쇼츠(목적: 조회수·성장, `CLAUDE.md` 목적·범위). 10-13 빡이사DB 01~04편으로 굳은 흐름이다.
**S6 일을 하면 이 문서를 먼저 연다** — 규칙 원문은 아래 «규칙 지도»가 가리키는 문서에 있고, 여기엔 순서와 위치만 둔다.

## 3. 점검기 항목 (`tools/s6_check.py` 머리말이 정본)

**R 글자 크기 · P 가림 떡칠 · Q 안개(녹임) · T 키프레임 영상대체(10-14)** · A 잇는 곳 말 끊김 · B 숨 없이 붙음 · C 전환 잔상 · D 자막 길이·빈칸 · **D2 자막 싱크(완성본 강제 정렬)** · **D3 나누기** · E 효과음 겹침·3초 반복 · **E2 효과음↔화면 변화** · **E3 한 편 같은 파일 반복** · F 끝 · G 음량 · H 멈춤 · J 잔움직임 · **K 자료 잘림·검은 띠** · **L 자막 겹침** · **M 빈 곳 표시·표시 글자 못 찾음** · **N 업체명·번호(OCR)** · S 소리만(원본 변화가 안 보임) · S2 자른 영역 밖 변화.
화면 변화는 **자막 띠를 빼고**, 칸(12×9) 단위·0.2~0.27초 간격으로 잰다(자막이 바뀌는 것을 화면 변화로 세지 않는다).

## 4. 점검기가 못 보는 것 — 눈·귀로

- 확대할 때 **좌우** 잘림 · 광고 이미지 속 **로고·그림 글씨 상호** · 소리 자체(들어 보지 못했으면 «못 들었다»).
- 표시가 «그 말»에 맞는지(뜻) — 자리·시각은 점검기가, 고른 대상이 맞는지는 사람이.

## 5. 함정 (실측)

- whisper 단어 시각은 0.3~0.6초 틀린다 → 강제 정렬(10-14). 정렬도 긴 덩어리를 한 번에 하면 경계에서 한 음절씩 밀린다 → **자막 하나마다 앞뒤 자막을 같이** 정렬(점검 D2).
- 효과음은 이 저장소 6개만 돌리면 반복된다 → 라이브러리 후보 `sfx_pick.py`, 한 편 같은 파일 2회까지(E3).
- 픽셀 덩어리로 표시 자리를 찾으면 버튼·테두리가 섞여 치우친다 → 감쌀 글자 OCR(10-14).
- 정수 픽셀 자르기 + 숨쉬기 = 잔흔들림 → 소수점 보간(EXTENT), 의도한 움직임만(10-13).
- 장면 경계는 원본 전환 프레임에 맞춘다 — 앞서 시작하면 이전 화면이 새 창으로 비친다(10-14 04편 471.3).
- 원본 쪽 넓히기는 구운 자막·작업표시줄 줄(y 945) 아래로 가지 않는다.
- 점검기 H(2초 멈춤)를 줌·팬으로 때우면 «키프레임만으로 영상대체»가 된다(10-14 04편) → 멈춤은 **새 정보**(쌓기·하드컷·얼굴)로 끊는다.
- 원본 디자인 슬라이드를 `live` 로 쓸 때 장면 시작은 그 요소가 **다 나타난 뒤**(원본 전환 중 빈 화면이 비친다 — 03편 1965.7·04편 494.5), 바탕은 원본 색 그대로(`flat`).
- `board` 장면 첫 요소를 페이드로 시작하면 하드컷 순간 빈 화면 한 프레임이 튄다(점검 C «튀는 한 프레임» — 10-15 04편 494.5) → 장면에 처음 보이는 요소는 첫 프레임부터 다 보이게(board.py `first_s`).
- 원본 슬라이드 조각(`live`) 위·아래에 이웃 요소 자투리(검색 칸 아랫단·칩 그림자)가 몇 px 걸리면 띠처럼 보인다 → 자르는 자리를 옮기고, 걸리는 원본 칩은 잘라 내고 코드 칩으로 다시 얹는다(03편 «오래 게재 = 검증된 광고»).
- 한 장면이 화면 위 절반만 쓰면 비어 보인다 — 요소가 하나뿐인 구간은 크게 가운데, 둘째 요소가 나올 때 하드컷으로 재배치(03편 내 눈/데이터 기준).

## 6. 편집 방식 — 레퍼런스 30편 + 통과 01·02편 (10-14 «편집 스킬 다시 학습해»)

반려 03·04편(1차)과 통과 01·02편을 나란히 보고, 레퍼런스(`기록/조사_강의쇼츠구조_1013.md` 1-4~1-6)를 다시 대조해 굳힌 것.

| 말 따라 쌓기 | 말 1~2초마다 새 정보: 단계 칩·큰 글자·밑줄·상자·✓✕·커서 (`board` layers, `at`=원본 초) | 같은 그림을 줌·팬으로 훑기 |
| 장면 바꿈은 하드컷 | 샷 경계 = 말 경계·원본 전환 프레임 | 페이드·푸시·녹임(«안개») |

| 길이 40~60초(10-16) | 엔딩 포함 40~60초. 넘치면 되풀이(앞에서 한 말 다시)·군말(«뭔 말인지 이해되세요?»)·덧붙임(«수강생 많이 키워봤잖아요»)부터 덜고, 자르는 점은 실제 쉼에서만. 엔딩 CTA 는 2.7초 + 앞 숨 0.6 + 끝 0.4 | 60초 넘는 쇼츠(03 v4 67초·04 v3 72.8초 «쇼츠 너무 길어») · 말이 쉼 없이 이어지는 자리에서 잘라 단어 반쪽 |
| 이어 붙이기·자막 강조(10-16 05편 폐기) | 조각 끝은 말이 닫힌 자리(«~하세요/~입니다/~거든요»). 자막 노란색은 그 박자의 진짜 강조어 하나만 | «꺼주셔야 하는데»에서 끊고 다른 화제 → «딴길로 샌거같잖아» · «원본, 원본, 원본» 앞 하나만 노랑 → «강조하는거아니면 노란색칠하지마» |
