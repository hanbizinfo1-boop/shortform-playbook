# 구조·대본 강령 — 훅 · 본문 · CTA · 쉬운 말 · 금지 표현 (학습 전 뼈대)

> 왜 이 문서가 맨 앞인가: 세 저장소에서 «영상미는 좋은데 반응이 없다»가 두 번 나왔다.
> - 분양 광고주 3차(09-23): «편집 자체는 부드럽게 잘 했고 나쁘지않음 … 이상하게 문의넣고 싶지 않음 … 이대로 나가면 DB 엄청 안뽑힐 것»
> - 한비즈 3안 타이포(10-12): «이 형태로 주말간 돌려보았는데 DB감도가 좋지않았다 해서 기존 레퍼런스보고 검증된 구조로 하고싶다고 하심»
> → **말의 구조가 먼저, 영상미는 그 위에.** 상위 광고는 «영상 재료는 오히려 단조롭다 — 모델하우스 워킹 한 컷을 끝까지 쓴 광고(116일)».

## 2. 훅 — 첫 1~5초

- **첫 5초 안에 후킹 요소 3개 이상**, 오프닝은 영상(09-28 클라이언트 «초반에 후킹될 요소 많이», 09-27 «초반은 이미지가 아니라 영상»).
- 훅 = **첫 프레임 · 첫 문장 · 화면 글자 · 약속**의 네 겹. 첫 프레임은 소리 없이도 읽혀야 한다. 긴 인트로·채널 범퍼 생략(롱폼 web-research §3).
- 유형 7: 결과 먼저 / 정확한 질문 / 문제-해결 / 스토리 티저 / 놀라운 주장 / 시각 공개 / 직접 약속(같은 출처, 2차 자료).
- 우리 쪽에서 쓴 훅: 호명(«정책자금 필요하신 대표님들 주목해주세요») · 가격 놀람 질문(«한강 보이는 신축이 6억대에 가능하다고?») · 초기 자금(«계약금 천만 원으로 잡는다고요?», 상위 5편 중 4편) · 시간 약속(«30초만 집중하세요!», M06) · 상식 뒤집기(«돈 주세요» → «제가 왜요?») · 반전 리듬(«아 네네네 해주세요»).
- **훅은 3개로 A/B** — 본문 하나에 첫 3초만 바꿔 CTR 로 고른다(분양 v3).
- 레퍼런스 훅은 **구조·느낌만**(누가 먼저 말하나·반전 지점·장치) — 첫 대사는 새로 쓴다(10-12).
- **상단 고정 제목 2줄**(1줄 노랑 + 2줄 흰, 검은 외곽선, 30초 내내) — 소리를 꺼도 무슨 광고인지 보인다(레퍼1). 유튜브 걸작 쇼츠도 맨 위 고정 제목 2줄. ☐ 한비즈 적용 여부는 첫 건에서.
- **강의형 쇼츠 상위 30편(10-13)**: 인사·인트로 0/30, 말은 0~0.6초에 시작, 고정 제목 띠 29/30, 시각 오프닝 연출은 2/30뿐 — 훅은 «제목 띠의 약속 + 첫 문장이 곧 본론». 주제 공식 «내 돈과 관련된 통념을 자격 있는 사람이 뒤집어 준다»(이유형·경고형·숫자 하나·화자 직함). 상세 `기록/조사_강의쇼츠구조_1013.md` 1-2·1-9.

## 2-1. 상단 제목 규칙 (10-13 — 상·하위 쇼츠 216편 비교, 상세 `기록/조사_쇼츠제목_1013.md`)

- 겉모양(숫자·질문·«이유»·강조색·글자 수)은 상위·하위가 같다(글자 수 중앙 17 = 17, «이유» 26% vs 21%). **갈린 것은 주제와 긴장**.
- T1 시청자 본인의 돈·DB·문의 · T2 1줄 상황(흰)/2줄 결과·반전(강조색), 줄당 8~12자 · T3 긴장 장치 하나(모순 쌍 / 손실 경고 / 사장님이 실제로 묻는 질문 / 즉시 이득) · T4 전문용어는 결과로 번역 · T5 «~하는 이유» 단독 금지 · T6 숫자 하나, 말에 나온 것만 · T7 말보다 세게 쓰지 않는다 · T8 같은 문형 연달아 금지 · T9 남 얘기·제도 안내·일반론으로 시작 금지.
- **10-13 사장님 확정 방향** — «제목을 저런식으로 설명하는듯이 적는게아니야 숫자의 법칙을 꼭 써야하는것도 아니고 나같으면 이렇게 짓겠어 / 손님들 데려오는 / 광고 세팅 비법»:
  - **틀 = 1줄 원하는 결과(사장님이 바라는 것) / 2줄 주제 + 비법·법·공식** — 짧은 명사구, 줄당 6~9자.
  - **설명하지 않는다** — 영상 내용(25~65세, 언어 설정, 4차 콜…)을 제목에 풀지 않는다. 답은 «비법»으로 감춘다.
  - 숫자는 선택(쓰면 하나). «~습니다/~마세요/~이유/~생기는 일» 같은 문장형 어미보다 명사로 끝낸다.
  - 앞선 T10(숫자 필수)·«생기는 일» 류 교정판은 **폐기**.
- 초안이다 — 우리 편 조회수로 다시 검증해 고친다.

## 3. 본문·CTA

- **말의 절반을 돈·조건에**, 장점은 한 줄로 압축(«없는 게 없어요»). 브로셔 낭독 금지(분양1·2 는 장점 나열이 대본의 약 60% — 반려 원인 분석).
- (내부 영업 구조 — 공개본에서 뺐다)
- **문의 장치를 3개 이상**(초기 자금 최소 · 선착순/마감 · 자격 완화 · 사은품/혜택) — 단 사실인 것만.
- **CTA 는 고정 + 버튼**: 끝 «더 알아보기» 버튼 + 손가락/커서, 필요하면 중간 CTA 1회(10초 안). CTA 버튼은 마지막 컷 하나(분양 6차: 중간 버튼 중복 반려). 끝 버튼 문구는 랜딩 첫 화면에 맞춘다(한비즈 «신청하고 내 한도 확인하기»).
- **대상 호명은 CTA 바로 앞**(«헌 집에서 새 집으로 갈아타실 분들», «아이 키우시는 분들»).
- **사람 얼굴 0편**(분양 상위 광고 11편 공통 — 상담사·진행자·AI 모델이 나온 광고는 집행 8~65일). ☐ 한비즈는 대표 출연을 원하신다(S1) — 이 관찰은 분양 한정 표본이라 충돌로 적어 둔다.
- 1인칭 구어체, 길이 32~57초(분양 상위). 한비즈 광고는 1분 이내.

## 4. 쉬운 말 · 숫자 · 금지 표현

**쉬운 말**(10-12 «너무 어렵대 언어들 숫자들 시청자가 계산하게 시키는거자체가 안읽히는 광고»)
- 친구한테 말하듯. 한 문장에 숫자 하나. 비교·곱셈·%를 시청자에게 계산시키지 않는다 — 결과만(«1년에 이자만 천만 원 넘게 아껴»).
- 반올림은 아래로(4조 7,143억 → «4조 7천억»), 위로 반올림 금지.
- 사장님 피드백 대본을 고친 예(병행작업 대본6): «2억 이상 받을 수 있으니까»(보장 → 뺌) · «4조 7200억»(실제 4조 7,143억 → «4조 7천억») · «제조업 희망 자금»(공고에 없는 이름 → «전용 자금이 따로 있어») · «받아드리고»(중개·대행처럼 들림 → «같이 준비해 줄게») · «자금 소진이 엄청 빠르게»(미확인·조급함 → «예산 다 쓰면 그해 신청은 끝이야»).

**쓰면 안 되는 말 (병행작업 요구 대장 E · 정책자금 조사 «주의 11» · 분양 규제)**
1. 보장: «무조건» «100%» «○억 확정» «받을 수 있다»(심사·감액 가능) — 승인·금액·매출 보장
2. 중개·대행처럼 들리는 말: «대행해 드립니다» «받아드립니다» «승인 보장» — 정책자금 공고의 제3자(브로커) 부당 개입 조항과 직결
3. 자격 과장: «누구나» «제조업이면 다» «자격 없어도» «서류 만들어 드림»
4. 공공기관·공무원 연상(정치인 사진·관공서 로고·실존 기관 직인)
5. 조급함: «오늘만» «마감 임박» «대표님만 안 받아가실 건가요?»
6. 고정값처럼 보이는 변동값: 금리는 날짜 병기(«2026년 10월 기준»), 한도는 «이내»
7. 미확정을 확정처럼: «예정/가능/계획» 꼬리가 떨어지면 확정으로 읽힌다(분양 «개통 예정·계획 단계» 꼬리말)
8. 한정 조건 빠뜨리기: «6억대»는 같은 화면에 «84타입 1,775세대 중 156세대»(8.8%)
9. 근거를 지어 붙이기: 들은 숫자에 출처 꼬리말 금지(09-22 «그냥 들은 거라서 표기하지마 클라이언트가 말해준거야»)
10. 실제 고객 상호·얼굴(동의 없이), 사례에는 «개인 사례» 고지
11. 입주가 빠른 것처럼 읽히는 연출(분양 리스크 문서)
- 끝 작은 고지(한비즈 예): «※ 승인 여부·한도는 기관 심사에 따라 달라집니다. 수임료·용역비는 상담 때 안내드립니다.»

- 대본 단계에서 «대본에서 뽑히는 시각 요소»를 같이 뽑는다: 숫자 / 조건·혜택 / 시설·아이콘 / 입지 / CTA(분양 대본 원형) — ④ 콘티의 입력.
