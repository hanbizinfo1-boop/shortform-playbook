# 템플릿 서랍 · 느낌 — 체계와 계승 후보 (학습 전: 서랍은 비어 있다)

> 사장님 10-08(롱폼): «각 단계마다 참고할 템플릿을 여러개 만들어두고 영상 내용과 소구에맞게끔 그 템플릿에서 골라서» · «단계별로 명칭이있어야하고 어떤 느낌으로 해달라고 얘기했을때 각 단계에서 특정 템플릿을 골라서» · «도형짜집기 합치기등으로 흉내내는 퀄리티낮은 도형흉내는 금지» · «템플릿의 퀄리티는 각 유튜브에서 강의하는사람들이나 조회수높은 완성물 쇼츠 그리고 내가 보내줬던 링크들 … 단계별로 또 각 연출주체별로 또 도구별 템플릿을 쌓아야해».
> 이 저장소는 그 체계를 숏폼용으로 받는다. **아직 템플릿은 0개** — 아래 «계승 후보»는 다른 저장소에서 통과했거나 만든 것의 목록이고, 옮길 때 견본을 다시 만들어 «대기»로 시작한다.

## 2. 템플릿 한 개 = 폴더 하나 (`templates/<ID>_<영문이름>/`, 규격은 `templates/README.md`)

```
template.json   매니페스트: id·name·drawer·engine(html|ae|pil|design|aivideo)·use_when·avoid_when·situations(SP)·
                slots(이미지 칸 source: codex|crawl|real_capture|brand|char2d|doc|aivideo)·drawn_allowed·keepout·sfx_roles·
                duration·status(신규|시안|대기|통과)·passed[]·rejected[](원문)·from(원본 도구 경로)
render.*        render(slots, timing, ctx) → 알파 MOV / mp4
sample/         견본 입력 + 견본 렌더 + 정지 3장
history.json    쓰인 건·컷·통과/반려(원문)·점수
```

**도형 흉내를 기계로 막는다**(롱폼 3-3장): 사물은 전부 이미지 칸, 코드로 그려도 되는 건 `drawn_allowed`(카드 바탕·구분선·테두리·밑줄·형광펜·말풍선 바탕·UI 위젯 자체·차트)뿐. 이미지 칸이 비었거나 출처가 없으면 렌더하지 않고 차순위로.

## 5. 서랍을 채우는 세 길 (롱폼 9장과 같다)

① 통과 장면 승격(장면 도구 → 칸을 비운 템플릿) ② 다른 저장소 시안을 세로 규격으로 이식 ③ 레퍼런스 해부(`ref_study`)에서 사장님이 고르신 것. 새 템플릿은 견본을 만들어 갤러리에 올리고 첫 실전은 «대기». 점수: 통과 +2 · 무반응 +1 · 반려 −3 · 같은 이유 반려 2번이면 그 상황을 `avoid_when` 에.
