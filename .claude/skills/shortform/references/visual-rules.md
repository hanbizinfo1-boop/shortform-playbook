## 3. 장면 스펙 틀 — 모든 모션그래픽 컷 (실행자·렌더러에게 주는 지시서, 영어 자기완결형)

```
SCENE: <id> · DURATION <s> · 1080x1920 · <fps ☐> · alpha <yes|no>
MOTIF / PALETTE(3 colors; comparison: one per side) / TYPE(font path, keep-all, min size ☐)
KEEP-OUT BOXES: caption ☐ · person ☐ · fixed bars ☐        ← vertical-spec.md 2장
WORD-TIME TABLE / SHOT TABLE(≥0.6 s apart, entrance 4–8 f ease-out, NO overshoot)
EXACT STRINGS (rendered by font engine, punctuation included): "…"
BACKGROUND (≥2 layers or a panel flip) / ENTRANCE (E1–E9) / EMPHASIS (one) / TRANSITION (X1–X6, same one ≤3 per film)
END HOLD / SOUND (role → file; 0.3–1 s breath before the big hit)
GUARDRAILS: no logos/company names (○○), no invented numbers, no emoji, no template-card lists, no neon/rainbow,
            no CSS-drawn phones/people (use <img>), no HUD labels/page numbers, no shake, text never copies the narration
START: show the word-time table + 3 stills before writing code
```

## 4. 타이포 전용 장면 강령 (쇼츠광고 J 카드, 10-12 — 근거: 유튜브 인기 5편 + 실제 광고 5편)

1. 글자는 «나타나지» 않는다, «사건»이 된다 — 이름 붙은 등장 하나(E1 하드컷 · E3 역팝 · E4 블러 인 · E5 타자 · E6 마스크 드러남 · E7 음절 계단(한 편 2~3곳) · E8 카운터 · E9 도장(한 편 1번)). ~~E2 번짐→정착~~은 흔들림으로 반려 → 외곽선 → 채움.
2. 배경은 판이 아니라 무대 — 최소 두 층(색 면 + 질감/빛/흐린 물체). 단색은 그 자체가 컷(판 반전)일 때만.
3. 블러는 입구와 출구에만 — 읽는 동안 0.
4. 튀는 건 크기가 아니라 대비.
5. 멈춘 글자도 숨 쉰다 — 푸시 인 +3~6%/1초.
6. 전환은 글자나 색 면이 만든다 — 크로스 디졸브 금지(X1 판 반전 · X2 글자 속으로 · X3 블록·대각 와이프 · X4 줌아웃 펀치 · X5 플래시 · X6 휩팬).
7. 신뢰는 속도에서 — 큰 움직임은 배경·카메라에, 글자는 또렷하게 4~6자/초. 1박(≈0.47초) 카드엔 4자 이하, 글 있는 카드는 1박 밑으로 줄이지 않는다.
- 금융 신뢰 톤(토스 2편): 글자 하드컷·또렷, 감정은 배경, 튕김 0. 한비즈는 무신사(리듬)와 토스(톤) 사이.
- **고급감 점검(10-12 «아니야 너무 저렴해 디자인도 연출방법도»)**: 바탕은 매거진·3D·실재 질감(나무·종이) 중 하나, 시안 2~3개 먼저 · 빵빠레 금지 · 목록은 물건에 담기 · 큰 숫자는 3D 블록 글꼴 · 전환은 물리 동작.

## 5. 이미지 원칙

- **레퍼런스를 먼저 본다** — «레퍼런스 없이 상상해서 만든 이미지는 경험상 다 별로였다»(09-22).
- **한글·지명·역명은 AI 에 맡기지 않는다** — 바탕만 생성, 글자는 PIL/폰트(Pretendard Bold · UI 재현 Noto Sans KR 500 · 맑은 고딕 25px 은 받침 뭉개짐).
- 사람 장면은 «사진기로 찍은 사진» 톤(CG 질감은 영상으로 옮겨 간다 — `ai-video.md`).
- 화면 속 글은 회색 줄·블러가 아니라 **읽히는 예시 글**(«뭘 물어보고 뭘 대답하는지 예시로 글자로» 10-07).
- 배경 서류·견본은 **실제 자료 기반**으로, 글자가 작게나마 읽히게(10-12 «실제 자료 기반으로 글자가 작게나마 보이게끔»). 자리표시 도형 서류 금지.
- 실존 건물·상표를 닮게 그리지 않는다(«본사 느낌» 일반 타워). 실존 기관 직인·은행 로고 넣지 않는다.
- 자료는 카드에 가두지 않고 날것으로 크게, 위치는 한 자리에 고정(분양 5·6차). 자료는 «들어가서 짚는다»(3D 기울어 들어옴 → 테두리 → 빨려 듦).
- 누끼는 크로마 그린, **소재가 녹색이면 마젠타 키**(`min(R,B) − G > 40`, 통장 표지 사례).
- Codex: 저장소 루트에서 호출 · 프롬프트에 «후처리 명령(convert·magick) 실행 금지» · 사람+밧줄은 self-harm 으로 막힘 · 결과 경로 이중 확인.

## 7. 함정 (원본에서 확인된 것)

AE «충돌 복구 옵션» 창이 `AfterFX -r` 를 멈춘다(감시 `run_ae_guarded`) · 위치 속성에 ease 배열 1개 · 부모 묶기 50%→자식 200% · AE 는 부모 불투명도를 물려받지 않음(글자 퇴장 따로) · 크롬 `--screenshot` 은 절대경로 · 정지 이미지는 ffmpeg `-loop 1 -framerate 30 -t` · 이중 인코딩 금지(컷은 CRF 16/slow 한 번, 이어 붙이기는 `-c:v copy`, 설정·키프레임 간격 통일) · 4:2:0 압축에서 빨간 글자가 먼저 번진다(카드 글자는 흰색·골드) · FCP XML center(위치)는 프리미어에서 화면 밖으로 나간다(위치는 파일 안에서) · XML 로 옮기면 AE 에만 있던 모션이 사라질 수 있다(프레임 대조).
