# S7 — 2D 재현 설명 쇼츠 (10-29~)

사장님 10-29: «기존방식 좀 폐기하고 다른방향으로» «완전 영상은 2D애니메이션(계속 움직이면서 지루하지않은) 근데 귀엽거나 그런거보단 세련되게»
«내가 하고싶은건 2d로 설명하는 느낌이야 2d로 재현해서 설명하는 느낌» «쇼츠는 어지간하면 힉스필드안썼으면좋겠어 무조건 2d로 설계해봐»
«2d애니메이션 에펙을쓰든 클로드디지안을쓰든 블렌더를쓰든 리모션을쓰든 그건상황에 맞게 알아서»

## 1. 한 줄

롱폼의 **목소리는 그대로**, 화면은 전부 **그 이야기를 재연하는 2D 장면**(글자는 자막만). 유료 영상화 없음.

## 2. 도구 (10-29 «리모션써도되고 / 에펙 써도되고 / 블렌더 써도됨 / 괜히 쓰면안된다고 단정짓지말것»)

어느 도구도 «안 쓴다»고 단정하지 않는다 — 장면에 맞는 걸 고른다.

| 도구 | 언제 |
|---|---|
| **Remotion**(`tools/remotion2d/`) | 기본 렌더 엔진 — 레이어 이미지에 소수점 변환(떨림 없음)·감속·모션 블러, 계획 JSON 으로 자동. 회사 라이선스(4인↑)는 사장님 판단 |
| After Effects | 손맛 나는 캐릭터 리깅(퍼펫 핀)·이펙트가 필요할 때. 스크립트 렌더(`AfterFX.exe -r`) |
| Blender | 진짜 3D 카메라 이동·깊은 공간이 필요할 때(레이어 평면 + 카메라, Grease Pencil) |
| `tools/anim2d.py`(파이썬) | 첫 시범에 쓴 합성기 — 정수 픽셀·bob 때문에 떨림 반려(10-29). 정지 화면 빠른 확인용으로만 |
| 힉스필드·Kling | 쇼츠는 2D(«어지간하면 힉스필드안썼으면») · Kling 폐기 |

## 3. 흐름

1. 전사(`transcribe_words.py`) → 구간 고르기(40~60초) → 콘티 표(대사 · 재현 장면 · 설명 그래픽 · 움직임).
2. 숫자·문구는 **원본 말 + 원본 구운 자막**과 대조(«3,400씩» 받아쓰기 → 원본 자막 «300~400만 원씩»).
3. **레이어 그림은 Codex 한 세션에 몰아서**: 배경판(사람·소품 없는 빈 공간) · 인물 포즈별 전신(같은 인물, 흰/투명 바탕) · 소품 낱개. 그림체 기준 `소재/빡이사신규/시안/style_A_editorial_flat.png`(에디토리얼 플랫, 남색·미색·회색 + 번트 오렌지).
4. `python tools/layer_cut.py <레이어폴더>` → `*_cut.png`(Codex 투명 그림의 빛 번짐 테두리 제거).
5. 계획 JSON(`tools/remotion2d/README.md`) → 정지 화면 확인 → 전체 렌더.
6. 효과음·BGM: `sfx_overlay.py` 큐(그림 등장·동작에 붙임) — 시범판은 아직 안 넣음.

## 4. 움직임 원칙 (지루하지 않게, 세련되게)

10-29 시범 반려 4가지(«말 엄청끊김» «글자는 어지간하면 자막으로만» «흔들림이 심함 키프레임 흔들림잡아야함» «아무것도안하고 반복됨이 지속되는경우가 너무김»):
- **말끊김 검사기(10-29 «검사기넣어서 문제있으면 무조건 반려해»)**: `s7_prep` 이 조각마다 앞말·자막·뒷말을 강제 정렬 → 자르는 점 = 앞말 끝~말 시작(말 끝~뒷말 시작) 사이 최저 음량. 그 점 소리가 말 대비 −18dB 보다 크면(쉼 없는 자리) ERROR, ERROR 가 하나라도 있으면 렌더하지 않는다. 전사 시각은 0.3초쯤 일러서 그대로 자르면 앞 문장 꼬리가 묻는다(10-29 실측).
- **타이밍은 낱말 소리 시각**: 샷 경계·사건 박자·자막·효과음 모두 계획에 «낱말[@n][+초]» 로 쓰고 강제 정렬 시각으로 바꾼다(«대본이랑 장면 정합성좀 타이밍좀»).
- **업무 장면은 종이·보드 대신 실제 일하는 화면**(10-29 «종이가아니라 사업자느낌으로 … DB성과데이터라던가»): 광고주 관리 화면·DB 성과 데이터·광고 관리자. 업체명 ○○, 지어낸 수치 대신 막대.
- **돈 화면은 진짜 사업체처럼**: 기업뱅킹 거래내역(사업자 계좌·계좌번호 가림·출금/잔액 칸), 금액은 예시를 하나 두고 빠지는 흐름(화면에 «예시»).
- **말 조각은 문장 끝에서만**(-요·-다·-죠·-까). «-고·-서·-는데»로 끝나는 조각 금지. 자르는 점 = 마지막 단어 끝~다음 단어 시작 사이 최저 음량(단어 끝 시각 그대로 자르면 꼬리 잘림).
- **화면 글은 없다 — 자막만.** 숫자·개념은 사물·동작으로(50만 원 = 돈다발 건네기, 40곳 = 폴더가 쌓임, 12시간 = 창밖 낮→밤).
- **떨림 0**: 카메라는 레이어 통째 소수점 변환, 정지한 물건은 움직이지 않는다(bob·숨쉬기 없음), 크기 바뀜은 소수점.
- **상호작용이 쉬지 않는다**: 말 단어마다 사건 하나(건네기·던지기·켜짐·쌓임·바뀜), 사건 사이 1.5초 넘지 않게. 같은 반복 움직임만 1.5초 넘게 이어지면 안 됨.
- **샷을 대사마다 고른다**(10-29 «통장 입금이나 그런거 좀 사용하고 좀 여러가지 연출기법» «몰입감이나 대사에 딱 어울리지않게»): 한 무대에 소품만 바꾸지 않는다 — 클로즈업·인서트(폰 은행 앱)·어깨 너머·1인칭·위에서·분할 화면·타임랩스·회상·플래시 몽타주. 돈은 은행 앱 입금·이체·잔액 화면(금액과 한두 단어만).
- **상호작용 = 원인과 결과**(10-29 «양쪽으로 움직이는 키프레임만 주지말고 서로 내용에맞게 상호작용»): 미끄러져 들어오고 나가기만 하는 키프레임 금지. 누르면 바뀌고, 맞으면 튀고, 꽂히면 차고, 빠지면 줄어든다.
- **카메라는 늘 움직인다**(밀기·당기기·옆으로, 장면당 1.00↔1.09). 배경은 깊이 0.4 로 덜 움직여 시차.
- **화면 안에 늘 흐르는 것 하나**: 날아가는 지폐, 컨베이어 폴더, 도는 시계, 빠지는 수위.
- **연기는 포즈 바꾸기**(말 박자에 맞춰 그림 교체)와 물건 주고받기. 숨쉬기·들썩임 없음(떨림으로 보임). 오버슈트 0, 등장 6프레임 감속.
- **사건은 그 말이 나온 순간에**(단어 시작 시각), 새 사건은 혼자 0.6초 이상. 자막은 y 1500.
- 장면 사이 하드컷. 렌더 중 0.6초 넘게 화면이 멈추면 WARN.

## 4-1. 제목·후킹 (10-29 확정)

- **제목 = 구피디 썸네일식**(«글자에 칠해놓고»): 위쪽 2줄 — 1줄 흰 글자 + 두꺼운 검정 테두리, 2줄 연두 붓칠 띠(`brush_band.png`, Codex → 불투명 영역만 자른 `brush_band_tight.png`) 위 **검정 글자** — 위아래 색 대비를 다르게(10-29 «위아래 색대비 다르게»). 띠는 둘째 줄만 덮고 첫 줄 글자를 가리지 않게, 두 줄 사이 약 22px(«안가려지게 … 간격이 너무떨어지면 좀 별로»). Pretendard Black. 첫 0.35초 크게 → 제자리, 끝까지 고정. 제목은 **경험형**(1인칭 겪은 일 — «월 2,500 팔던 사업 / 제 손으로 접었습니다»). 위 0~440 은 제목 자리 — 장면 핵심은 그 아래.
- **첫 3초 후킹**(«초반 3초 후킹이 굉장히 중요»): 이야기 중간부터 시작하지 않는다. 원본에서 가장 센 숫자 + 반전 대사를 맨 앞에(콜드 오픈) → 질문 한 줄 → 본 이야기. 3초 안에 숫자 치솟음·쏟아짐·반전(꺼짐) 같은 사건 셋.
- **배경음악 깔린 원본 구간**: 그대로 자르면 음악이 끊긴다 → demucs 로 목소리만 뽑아(plan `voice`) 자르고 검사한다.
